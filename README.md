# projectLTWEB

Bài thực hành quản lý mã nguồn với Git và GitHub.

## Công nghệ
- HTML và CSS
- Visual Studio Code
- Git và GitHub
- Somee Hosting
- GitHub Actions

## Chạy trên máy
Mở file website/index.html bằng trình duyệt.git init

## Website demo

http://TriisDayNe.somee.com/index.html

## Triển khai tự động

Website được triển khai lên Somee bằng GitHub Actions.

Quy trình:
1. Chỉnh sửa nội dung trong thư mục website.
2. Lưu file, tạo commit và push lên GitHub.
3. Khi nhánh main nhận commit mới, workflow deploy tự chạy.
4. Kiểm tra GitHub Actions và website Somee.

## Thực hành nhánh

Nội dung này được bổ sung trên nhánh feature/update-readme
và gộp vào main thông qua Pull Request.git add README.md


## Thực hành Source Control trong VS Code

Tạo nhánh, stage, commit và push bằng giao diện VS Code.
